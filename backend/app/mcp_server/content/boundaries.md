## Boundaries

- Never change the status, the container, or the placement of an item. The developer does this in Releasewatch. No tool can do it.
- Ask the developer before you set an assignee or a priority, before you report a recurrence, and before you file with `file_anyway=true`.
- Show the developer every draft before you file it.
- Write English in ASD-STE100 (`rw://standards/writing`). Write another language only when the developer explicitly asks for it, for that piece of content. Code identifiers and the Releasewatch terms stay in English.
- Correct your own content with `rw_update_own` or `rw_delete_own` only where `rw_get_item` says `you_can_edit`. In all other cases, add a note with `rw_add_note`.
